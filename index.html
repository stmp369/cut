Firebase config needed

This file has a placeholder Firebase config. Open cutting-register.html in a text editor, find the firebaseConfig object near the top of the <script> section, and paste in your project's values from Firebase Console → Project settings → General → Your apps → SDK setup and configuration.

const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};

Also make sure Firestore Database is created in your project (any region), with rules that allow read/write for this app's use case.
